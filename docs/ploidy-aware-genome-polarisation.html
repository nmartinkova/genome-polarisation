Genome polarisation with diemr

Chapter 9 Ploidy-aware genome polarisation

Genome polarisation with the diem algorithm was originally developed for biallelic genomic sites, where each site contributes one of four possible states: an undetermined genomic state or missing data, homozygous for one allele, heterozygous, or homozygous for the alternative allele. Many biological datasets, however, contain genomic regions of different ploidy within the same individual. These include sex chromosomes, pseudo-autosomal regions, organellar genomes, and lineage-specific aneuploidies.

The diem model of diagnostics assumes that the information contributed by a site scales with the number of allele copies sampled per individual (Baird et al. 2023). Genomic compartments that are haploid or hemizygous therefore contribute less information per site than diploid regions. Treating all sites as diploid can bias likelihood estimates and hybrid-index calculations unless ploidy differences are explicitly accounted for, particularly in cases where diagnostic markers accumulate in non-diploid genomic regions.

This chapter describes how diemr handles ploidy-aware genome polarisation and how hybrid indices can be calculated consistently across compartments of different ploidy.

9.1 Mapping compartments and their ploidy

A compartment is a subset of sites for which we can specify ploidy for each of the analysed individuals. For example:

  • autosomes: ploidy = 2 for XX and XY individuals,
  • X chromosome: ploidy = 2 for XX, 1 for XY,
  • mitochondria: ploidy = 1,
  • Y chromosome: ploidy = 0 or 1 depending on sex.

We use the term compartment rather than chromosome because compartments are defined by ploidy regime, not by chromosomal identity. Moreover, when using parallel processing in diem, the grain of parallelisation is a compartment. Parallelisation is more efficient (less overhead) if compartments have the same size, which is not likely when each compartment corresponds to a chromosome.

The diem algorithm estimates an optimal polarity for each site. Individual ploidy enters through the compartment definition, which specifies how many allele copies are expected per individual for the sites in that compartment, and therefore how sites contribute to likelihood and to hybrid index calculation.

The key property is that each compartment has an associated ploidy value for each individual, and this ploidy determines how much each site contributes to the model likelihood and to the individual’s hybrid index.

Compartment ploidy is a required argument in diem analysis, and site polarities are infered from the model that is ploidy-aware. The compartment and ploidy mapping is illustrated with a worked example in Chapter (@ploidy).

filepaths <- c(system.file("extdata", "data7x3.txt", package = "diemr"),
                system.file("extdata", "data7x10.txt", package = "diemr"))
               
ploidies <- list(rep(2, 7),
                  c(2, 1, 2, 2, 2, 1, 2))

samples <- 1:7

CheckDiemFormat(files = filepaths, 
                ChosenInds = samples,
                ploidy = ploidies)
# File check passed: TRUE
# Ploidy check passed: TRUE

# Set random seed for repeatibility
set.seed(39583782)

# Run diem 
res <- diem(files = filepaths, 
            ploidy = ploidies, 
            markerPolarity = FALSE,
            ChosenInds = samples, 
            nCores = 1)

# Import polarised genotypes
gen <- importPolarized(file = filepaths, 
                       changePolarity = res$markerPolarity, 
                       ChosenInds = samples)

9.2 Hybrid index under varying ploidy

For diploid data, the hybrid index (_i) of individual (i) is the proportion of alleles belonging to one side of the barrier among all polarised sites. When different sets of sites originate from compartments of different ploidy, each compartment’s contribution must be weighted accordingly.

9.2.1 Per-site contribution

For a site (j) in compartment (c), with ploidy (p_c), the polarised genotype value (g_{i,j}) takes:

  • 0 = fully reference
  • 1 = fully alternative (haploid, hemizygous)
  • 0, 1, or 2 on diploid sites

To make contributions comparable across compartments, the site is scaled by the ploidy:

[ a_{i,j} = .]

Thus, a haploid “alternative” allele contributes (1), matching a diploid “2” on a diploid site.

9.2.2 Total hybrid index

Let (J_c) be the set of sites belonging to compartment (c). Let (M_c(i)) be the subset of non-missing sites for individual (i) in compartment (c).

For each compartment, compute the mean allele proportion:

[ *{i,c} = .]

Then compute the genome-wide hybrid index as the weighted mean across compartments, weighting each compartment by its count of non-missing sites:

[ *{i} = .]

This formulation ensures that:

  • compartments with more informative sites contribute proportionally more,
  • haploid regions contribute appropriately scaled information,
  • missing data does not bias the result, and
  • the hybrid index equals the classical diploid formula when all ploidy values equal 2.

9.3 Implementation in diemr

The function hybridIndex() automatically performs ploidy-aware calculations when invoked on a diem hybrid-index file or when given a ploidy= vector corresponding to compartments.

Example:

HI <- hybridIndex("HIwithOptimalPolarities.txt")

or for explicit genotype matrices:

HI <- hybridIndex(
  genotypes = gen,
  compartment = compVector,
  ploidy = ploidyVector
)

where:

  • compartment assigns each site to a compartment ID
  • ploidy gives the ploidy of each compartment

If neither argument is supplied, the function defaults to diploid calculations.

9.4 Interpretation considerations

Ploidy-aware hybrid indices behave identically to diploid indices when comparing individuals within a dataset—values remain constrained to ([0,1]) and reflect the proportion of ancestry belonging to the chosen side of the barrier. However, when regions vary strongly in ploidy (e.g., autosomes vs X vs mitochondria):

  • haploid regions produce allele proportions with lower sampling variance per site,
  • compartments with many sites dominate the genome-wide mean,
  • the influence of mitochondria or sex chromosomes depends strictly on their site count, not their biological magnitude.

When comparing datasets with different compartment definitions or different numbers of markers per compartment, interpretation must therefore focus on within-dataset structure, not absolute values across analyses.

9.5 Visualisation

All visualisation tools in diemr, including plotPolarized(), plotMarkerAxis(), and smoothed-state displays, accept ploidy-aware input without modification. The hybrid index passed to the plotting functions may be ploidy-aware or diploid; the heatmap remains the same because polarisation itself is not affected by ploidy. Only the hybrid-index ordering of individuals changes when ploidy-aware values differ from diploid summarisation.

9.6 Summary

  • Genome polarisation can integrate genomic regions of differing ploidy.
  • Each site contributes an allele proportion scaled by its compartment ploidy.
  • The genome-wide hybrid index is a weighted mean of per-compartment indices.
  • The implementation is fully automated in hybridIndex() when the ploidy information is present in the output of diem.
  • Interpretation should remain within datasets, as the weighting depends on marker distribution across compartments.
